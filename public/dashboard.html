Wie erstelle ich ein passendes Git-Repository? (Anleitung aufklappen)

Dein Repository braucht genau eine Datei im Hauptverzeichnis: ein Dockerfile. Der Server baut daraus automatisch deine App.

Option 1: KI-Prompt (empfohlen)

Kopiere diesen Prompt in Claude oder ChatGPT und beschreibe danach deine App:

Erstelle mir eine einfache Web-App mit einem Dockerfile, die ich auf einem Server deployen kann. Anforderungen: - Die App lauscht auf Port 80 (oder über Umgebungsvariable PORT konfigurierbar) - Das Dockerfile basiert auf einem schlanken Basis-Image (z.B. node:18-alpine, python:3.11-slim oder nginx:alpine) - Gib mir alle Dateien, die ich in ein GitHub-Repository hochladen muss - Das Dockerfile muss im Hauptverzeichnis des Repos liegen - Die App soll [HIER DEINE IDEE BESCHREIBEN]

Option 2: Minimales Beispiel (Node.js)

Drei Dateien reichen für eine funktionierende App. Erstelle ein neues Verzeichnis und lege diese Dateien an:

Dockerfile

FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install --omit=dev
COPY . .
EXPOSE 80
CMD ["node", "server.js"]

server.js

const http = require('http');
const PORT = process.env.PORT || 80;

http.createServer((req, res) => {
    res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' });
    res.end('<h1>Mein Hackerwerkstatt-Projekt</h1>');
}).listen(PORT, () => console.log(`Läuft auf Port ${PORT}`));

package.json

{ "name": "mein-projekt", "version": "1.0.0", "main": "server.js" }

Repository auf GitHub hochladen

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/DEIN-USERNAME/DEIN-REPO.git
git push -u origin main

Die HTTPS-URL deines Repos (https://github.com/...) trägst du dann unten ein.

Manuelles Deployment (Anleitung)

                

                
1. Mit KI generieren

                
Kopiere diesen Prompt in ChatGPT oder Claude, um eine funktionierende
                    docker-compose.yml zu erhalten:

                

                    
                    
Ich möchte meine Web-App mit Docker Compose deployen. Bitte erstelle mir eine
                        docker-compose.yml Datei. Sie MUSS das externe Netzwerk 'web' verwenden UND Labels für
                        caddy-docker-proxy haben, damit sie unter 'meinprojekt.hackerwerkstatt.de' erreichbar ist (ersetze
                        meinprojekt mit meinem echten Projektnamen). HTTPS wird automatisch von Caddy bereitgestellt. Die
                        Labels sehen so aus: caddy: meinprojekt.hackerwerkstatt.de und caddy.reverse_proxy: "{{upstreams
                        PORT}}".

                


                
2. Nutze diese Vorlage

                
Oder verwende direkt diese Vorlage. Speichere sie als docker-compose.yml auf dem Server.
                

                

                    
                    
services:
  my-app:
    build: .  # Oder z.B. image: nginx:alpine
    networks:
      - web
    labels:
      caddy: meinprojekt.hackerwerkstatt.de
      caddy.reverse_proxy: "{{upstreams 80}}"

networks:
  web:
    external: true

                


                
3. Starten

                
Führe diesen Befehl in dem Ordner aus, in dem deine Datei liegt:

                

                    
                    
docker compose up -d
